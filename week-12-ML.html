Diapositiva 7 – 4.1. Supervised Learning

ENSupervised Learning is the simplest machine learning model to understand in which input data is called training data and has a known label or result as an output. So, it works on the principle of input-output pairs. It requires creating a function that can be trained using a training data set, and then it is applied to unknown data and makes some predictive performance.

LecturaSiúpervaisd lérnin is da símplest mashín lérnin módel tu anderstánd in juich ínput déita is kold tréinin déita an jas a noun léibol or rizált as an áutput. Sou, it uorks on da prínsipol of ínput-áutput pérs. It rikuáirs kriéiting a fánkshon dat can bi tréind iúsing a tréinin déita set, an den it is aplaid tu annóun déita an meiks sam predíktiv perfórmans.

ESEl aprendizaje supervisado es el modelo más simple de entender: los datos de entrada se llaman datos de entrenamiento y tienen una etiqueta o resultado conocido como salida. Funciona con el principio de pares entrada-salida. Requiere crear una función que se entrena con un conjunto de datos de entrenamiento y luego se aplica a datos desconocidos, logrando cierto desempeño predictivo.

ENSupervised learning is task-based and tested on labeled data sets. We can implement a supervised learning model on simple real-life problems. For example, we have a dataset consisting of age and height; then, we can build a supervised learning model to predict the person's height based on their age.

LecturaSiúpervaisd lérnin is task-beist an téstid on léibold déita sets. Ui can ímplement a siúpervaisd lérnin módel on símpol ríal-laif próblems. For egsámpol, ui jav a déitaset konsístin of eich an jait; den, ui can bild a siúpervaisd lérnin módel tu predíct da pérsons jait beist on der eich.

ESEl aprendizaje supervisado se basa en tareas y se prueba con conjuntos de datos etiquetados. Se puede aplicar a problemas simples de la vida real. Por ejemplo, con un conjunto de datos de edad y estatura, podemos crear un modelo supervisado que prediga la estatura de una persona según su edad.

Diapositiva 13 – 4.3. Reinforcement Learning

ENIn reinforcement learning, the algorithm learns actions for a given set of states that lead to a goal state. It is a feedback-based learning model that takes feedback signals after each state or action by interacting with the environment.

LecturaIn rinfórsment lérnin, di álgoridm lerns ákshons for a guíven set of stéits dat lid tu a goul stéit. It is a fídbac-beist lérnin módel dat teiks fídbac sígnals áfter ich stéit or ákshon bai interáctin wid di enváironment.

ESEn el aprendizaje por refuerzo, el algoritmo aprende acciones, para un conjunto dado de estados, que llevan a un estado objetivo. Es un modelo basado en retroalimentación que recibe señales después de cada estado o acción al interactuar con el entorno.

ENThis feedback works as a reward (positive for each good action and negative for each bad action), and the agent's goal is to maximize the positive rewards to improve their performance. The behavior of this model is similar to human learning.

LecturaDis fídbac uorks as a riuórd (pósitiv for ich gud ákshon an négativ for ich bad ákshon), an di éiyents goul is tu máksimais da pósitiv riuórds tu imprúv der perfórmans. Da bihéivior of dis módel is símilar tu hiúman lérnin.

ESEsa retroalimentación funciona como recompensa (positiva por cada buena acción y negativa por cada mala), y el objetivo del agente es maximizar las recompensas positivas para mejorar su desempeño. El comportamiento de este modelo es similar al aprendizaje humano.

LecturaUans da mashín lérnin módel is bilt, it is tréind in órder tu guet di aprópriet rizálts. Tu trein a mashín lérnin módel, uan nids a hiúch amáunt of pri-prósesd déita. Jíer pri-prósesd déita mins déita in strákchurd form wid ridúsd nal váliuis, etcétera. If ui du not provaid pri-prósesd déita, den der ar hiúch chánsis dat áur módel mei perfórm térribli.
