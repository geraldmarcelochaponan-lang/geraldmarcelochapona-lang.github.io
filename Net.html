01 · Foundation

What is .NET and what is it made of

  • .NET is a Microsoft platform for building applications. It is not a programming language: it is the environment where code runs. It is free, open source, and works on Windows, Linux, and macOS.
  • CLR (Common Language Runtime): executes the program and manages memory automatically.
  • BCL (Base Class Library): pre-written code you can reuse for common tasks like files, text, and networking.
  • Compiler: converts the code you write into a format the machine can process.
  • SDK (Software Development Kit) and CLI (Command Line Interface): tools to create, compile, and publish projects.
  • NuGet: repository where you download libraries built by other developers.
With .NET you do not start from zero: the runtime, the libraries, and the tools are already included. You only write the logic of your application.
02 · Tools

Languages and key technologies

  • C# (C Sharp): the most used language in the industry.
  • F# (F Sharp): focused on calculations and data processing.
  • Visual Basic: used in companies with Windows systems.
  • ASP.NET Core: for websites and internet services.
  • Entity Framework Core: reads and saves data in databases without writing manual queries.
  • .NET MAUI (Multi-platform App UI): one code for apps on Android, iOS, Windows, and macOS.
  • WPF (Windows Presentation Foundation) and WinForms: for desktop programs on Windows.
The language is the same for all projects. What changes is the technology you choose depending on whether you build a website, a mobile app, or a desktop program.
03 · Engine

How it works inside

  • 1. You write the code in C#.
  • 2. The compiler converts it into IL (Intermediate Language), a language that does not depend on the processor type.
  • 3. At runtime, JIT (Just-In-Time) converts the IL into the machine code where the program runs.
  • 4. The CLR executes the program and controls memory and security.
The code is compiled once and adapts to the system where it runs. That is why the same program works on Windows, Linux, and macOS without changes.
04 · Impact

Performance and unification

  • Performance: in public tests (TechEmpower), .NET processes more web requests at the same time than Node.js and Java.
  • Unification: before there were three separate versions (.NET Framework, .NET Core, and Mono). Since .NET 5 there is one single version for all systems.
Today there is one single version of .NET for all systems, and it is optimized to handle many requests at the same time without losing speed.
05 · Future

Native AI and Cloud

  • AI: .NET includes Semantic Kernel, a library to integrate language models like ChatGPT inside C# applications without using Python.
  • Cloud: .NET is designed for server applications and microservices. .NET Aspire lets you create, monitor, and deploy distributed applications.
  • Docker: .NET generates small images with fast startup for containers.
If your application is already built in .NET, you can add artificial intelligence without migrating to another language or rewriting the project.
06 · Closing

Native AOT and conclusion

  • AOT (Ahead-Of-Time): compiles the program directly to machine code before running, without using JIT at runtime.
  • Result: instant startup and lower memory usage.
  • Ideal for cloud services that start and stop constantly (AWS Lambda, Azure Functions) and for devices with limited resources (Edge Computing).
  • Closing: .NET is one platform, with several languages, to build any modern application.
With Native AOT, the application is compiled for that specific machine: it starts immediately and uses less memory. That is why it works for cloud services that turn on and off all the time, and for devices with low capacity.
